내 여행 일정을 불러와 주세요

처음에는 개인 일정을 불러오기 전이라 날짜와 동선이 비어 있습니다.

  1. 별도로 받은 개인 일정 파일이나 전체 백업 파일을 휴대폰에 다운로드하세요. Drive에서 열어 보기만 했다면 먼저 기기에 저장하세요.
  2. 위의 일정·전체 백업 가져오기를 눌러 내려받은 .json 파일을 선택하세요.

일정과 방문 기록은 이 주소의 브라우저에만 저장합니다. 파일 전체와 예약 정보는 서버로 보내지 않습니다. 도보 연결을 켜거나 구간 조회를 누르면 해당 두 핀의 좌표만 FOSSGIS에 전송합니다.

다른 기기로 옮길 때는 전체 내보내기로 파일을 보관한 뒤 새 브라우저에서 가져오세요. 예전 파일 주소나 다른 주소의 기록은 자동으로 옮겨지지 않습니다.

가져온 뒤 배경 지도를 불러오면 지도 제공자에게 보는 지역이 전달됩니다. 외부 지도 링크는 직접 누를 때만 목적지 정보를 전달합니다.

대중교통 연결

켜면 현재 표시된 대중교통·이동수단 미확인 구간의 원래 좌표만 비공개 연결로 전송합니다. 원본 도보·도보 후보·통제 구간은 자동 대중교통 조회에서 제외하며, 모든 번호의 구간은 선택 카드에서 직접 요청할 수 있습니다. 이번 화면 세션은 최대60회이며 다시 연결해도 한도를 채우지 않습니다. 계정 전체의 요금·호출 한도는 아닙니다. 자동 재시도하지 않습니다.

응답은 현재 지도와 안내에만 표시하며 보관·내보내기하지 않습니다. 연결 코드는 공백 없는 ASCII 영문·숫자·기호 32~512자이며, 연결 설정 성공 시 입력란에서 지웁니다. 형식·설정 오류 시 입력을 유지합니다. 코드는 저장하지 않고 연결 해제·파일 가져오기·화면을 떠날 때 해제합니다. Kakao REST 키는 입력하지 마세요. 처음·복원·이 화면으로 돌아왔을 때는 연결이 꺼져 있으며, 연결 코드 입력과 켜기 전에는 대중교통 요청을 보내지 않습니다.

예약·이동 시간 메모

    위치·경로 출처와 연결 상태

    초록선은 원본 저장 또는 FOSSGIS에서 새로 조회한 보행 경로입니다. 가져온 복합 이동은 버스 파랑, 지하철·철도 보라, 환승 금색으로 구분합니다. 각 단계·선형·승하차·끝점의 출처와 시각을 카드에 표시하며, 원본 확인 주장은 현재 제공자의 확인이 아닙니다. 색 점선은 선형 근거 미확인, 회색 점선은 연결·진입 구간 미확인입니다. 구간 카드에 출처와 조회시각을 표시합니다. 시간은 보행 엔진 추정이며 휴식·현재 교통을 반영하지 않습니다. 선이 없는 구간은 경로·시간 미확인으로 남깁니다. 개략 핀과 현장 통제·진입점·계단은 방문 전에 확인하세요. 대중교통 연결을 직접 켠 경우 현재 응답을 표시하지만 실제 도로 정합·현장 통제·운영·출입구 확인을 뜻하지 않습니다.

    타일 표시는 이미지 로딩 이벤트에 근거합니다. 오류 안내 이미지도 로딩될 수 있으므로 실제 도로·해안선은 화면에서 직접 확인하세요. 개략도는 실제 지도가 아닙니다.

    배경 지도는 보는 지역을 OSM에 전달합니다. 외부 지도 링크는 누를 때 선택한 장소·좌표를 전달합니다. 도보 연결을 켜거나 구간 조회를 누르면 두 핀 좌표만 FOSSGIS로 전송합니다. 대중교통 연결은 비공개 연결 코드를 입력하고 직접 켤 때만 원래 두 핀 좌표를 전용 게이트웨이와 Kakao에 전송합니다. 일정 전체·예약을 URL로 보내거나 업로드하지 않습니다.

    배경: © OpenStreetMap contributors · Leaflet 1.9.4 (unpkg) · OSM 타일 이용 정책. 오프라인 지도 묶음·타일 선다운로드 기능은 없습니다.

    기록 보관·휴대폰으로 옮기기

    방문 기록 파일은 기존 방문·추가 기록만 합칩니다. 전체 내보내기는 일정·예약·저장 경로와 이 브라우저의 기록을 함께 담습니다. 개인 파일이므로 공유 범위를 확인하세요.

    다른 주소·기기·브라우저로는 자동 이전되지 않습니다. 예전 저장 키는 수정하거나 지우지 않습니다. 기기를 옮기기 전에 전체 내보내기 파일을 따로 보관하세요.
